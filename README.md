# Nice Gadgets — Product Catalog

An online store for phones, tablets, and accessories built with React and TypeScript. Browse the catalog, filter and sort products, view detailed product pages with color and capacity variants, and manage a cart and favorites list.

## Live Preview

**Live Demo:** [Nice Gadgets — Product Catalog](https://ratushnjakivanko-spec.github.io/react_phone-catalog/)

> ⚠️ Make sure the link above works in incognito mode before submitting.

## Technologies Used

**Core**
- React — UI framework
- TypeScript — Type safety
- SCSS — Styling

**State Management**
- React Context API — Application state (cart, favorites, theme)
- localStorage — State persistence

**UI/UX**
- React Router — Navigation
- Custom SVG icon set — UI icons

**Development & Deployment**
- Vite — Build tool
- ESLint / Stylelint — Code quality
- GitHub Pages — Hosting and deployment

## Getting Started

1. Clone the repository:

```
git clone https://github.com/ratushnjakivanko-spec/react_phone-catalog.git
cd react_phone-catalog
```

2. Install dependencies:

```
npm install
```

3. Run the project locally:

```
npm start
```

## Features

- **Responsive Design:** Optimized for different screen sizes and devices.
- **Navigation:** `react-router-dom` is used to navigate between the Home, Catalog, and Product Details pages.
- **Favorites & Cart:** Adding products to favorites or the shopping cart, with total price calculation, persisted in local storage.
- **Product Filtering:** Filter products by category (phones, tablets, accessories).
- **Sorting:** Sort products by criteria such as newest, price, and alphabetically.
- **Pagination:** Navigate through large lists of products, with a configurable number of items per page.
- **Product Variants:** Switch between color and capacity variants directly on the product page without a full page reload.
- **Theme Toggle:** Switch between light and dark themes.
- **Loader:** Indicates loading status for a better user experience.
