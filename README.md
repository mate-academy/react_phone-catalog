# React Phone Catalog

[Demo](https://Igor-hrm.github.io/react_phone-catalog/)

Online product catalog built with React and TypeScript, featuring product browsing, detailed product pages, favorites, and a shopping cart.

## Features

- Product search with URL synchronization and debounce
- Sorting and pagination with URL parameters
- Product details with image selection and available options
- Shopping cart with quantity management and automatic totals
- Favorites with persistent storage
- Product carousels featuring the latest models
- Loading skeletons and error handling
- Responsive layout

## Technologies

- React
- TypeScript
- React Router
- SCSS Modules
- Context API
- REST API
- localStorage

## Getting started

```bash
git clone https://github.com/Igor-hrm/react_phone-catalog.git
cd react_phone-catalog
npm install
npm start
```
